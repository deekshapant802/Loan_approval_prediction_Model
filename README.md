# Loan Approval Prediction Model

## Overview
This project is a machine learning-based web application that predicts whether a loan application will be approved or rejected based on applicant details.  
It uses a trained classification model and provides an interactive interface for real-time predictions.

## Features
- Real-time loan approval prediction  
- Simple and interactive UI built with Streamlit  
- Uses trained ML model with preprocessing (scaling)  
- Handles multiple financial and personal input features  


## Tech Stack
- Python  
- Streamlit  
- Pandas  
- NumPy  
- Scikit-learn  




##  How to Run
pip install -r requirements.txt  
streamlit run app.py
